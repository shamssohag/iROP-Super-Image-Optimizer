About The Project

A professional desktop application for bulk image optimization (resizing, format conversion, and compression) built with Python and CustomTkinter. It features a modern Windows 11-style GUI, RAW image support, audit report generation, system tray integration, and real-time process controls.

Features

  • Modern Windows 11 GUI: Clean, responsive CustomTkinter interface with fixed layouts and modern styling.
  • Camera RAW Support: Seamlessly reads and converts professional camera RAW files (Sony, Canon, Nikon, etc.).
  • Dynamic Resolution Control: Choose between keeping original dimensions, 2K, Full HD, Web, or Small sizes.
  • Advanced Format Conversion: Support for WEBP, AVIF, JPEG, PNG, and more.
  • Real-Time Controls: Pause, Resume, and Cancel operations smoothly on the fly.
  • System Tray Integration: Keep the application running silently in the background tray.
  • Auto-Generated Audit Report: Automatically generates a report.txt file detailing file sizes and space savings.

Supported Formats

Standard Formats .jpg, .jpeg, .png, .bmp, .webp, .ico, .tiff, .tif, .gif
Next-Gen Formats .heic, .heif, .avif
Camera RAW Formats .arw, .cr2, .cr3, .nef, .dng, .raf, .orf, .srf, .sr2

How to Use (.exe Application)

  1. Locate the iROP Super Image Optimizer.exe file on your computer.
  2. Double-click the executable file to launch the graphical user interface instantly. No Python or terminal setup is required!
  3. Select your source folder and optional destination path using the Browse buttons.
  4. Configure your target resolution, output format, and compression quality slider.
  5. Click Start Optimization and monitor progress in real-time. Use Pause, Cancel, or New Start buttons as needed.
  6. Closing the main window minimizes the application to the Windows system tray for background availability.
