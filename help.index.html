Help Center & Frequently Asked Questions

1. Brief Overview
iROP Super Image Converter & Optimizer operates 100% offline with zero cloud upload risks and no file limits. Without requiring heavy editing suites, it natively converts standard JPEG/JPG, PNG, and professional camera RAW files into next-generation WEBP/AVIF formats, preserves exact nested folder structures, and strips unnecessary metadata to reduce file sizes by 50% to 80% with no loss in visual quality.
Live Optimization: With its built-in Live Monitor feature, the app watches your source directory in real time, instantly detecting and automatically optimizing newly dropped or pasted images.
Intelligent Workflow: Features an intelligent skipping system that automatically bypasses previously processed files in the destination folder to prevent redundant re-rendering and save massive amounts of time. If a large batch is ever interrupted, you can reload your saved preset and effortlessly resume exactly where you left off.
2. General Information & Formats
No. The application is completely offline. None of your images are uploaded to any server or cloud, ensuring your data remains 100% private and secure on your local machine.
  • Standard & Web Formats: JPG, JPEG, PNG, WEBP, AVIF, HEIC, HEIF, BMP, TIFF, TIF, ICO, GIF, TGA, and SVG.
  • Camera RAW Formats: ARW (Sony), CR2/CR3 (Canon), NEF (Nikon), DNG, RAF (Fujifilm), ORF (Olympus), SRF, and SR2.
3. Settings & Preset Management
By clicking the "Save Preset" button in the options panel, you can export your preferred resolution, output format, quality slider, and checkbox settings into a reusable .json file. You can restore these settings anytime via "Load Preset". Additionally, checking "Include Paths" lets you save and load your source and destination directory paths alongside the processing options.
  • Resolution: Choose from presets including Keep Original, 2560px (2K), 1920px (Full HD), 1200px (Web), and 720px (Small). Larger images are proportionally downscaled using high-precision LANCZOS resampling while preserving the original aspect ratio.
  • Quality Slider: A slider value between 75 and 85 is optimal, providing substantial byte reduction (50%–80%) with virtually no perceptible loss in sharpness.
  • Empty Dest Path: Operates in In-place Overwrite mode, replacing original images in the source directory. Always choose a destination folder if you wish to retain your original files untouched.
  • Auto Open (Dest Folder): When checked, the application automatically launches your target directory in File Explorer the moment batch optimization finishes.
4. Smart Batching & Live Monitor
During batch processing, the application intelligently inspects the destination directory to check whether an optimized version of the target file already exists. If found, the app automatically Skips the file to eliminate redundant encoding, saving system resources and dramatically cutting down processing time on large collections.
When "Live Monitor" is enabled, the application continuously watches your source directory in real time after the initial batch is completed. Whenever new image files are added or dropped into the folder, the app automatically detects and optimizes them in the background. A live stopwatch on the status bar keeps track of total monitoring active time.
Whenever newly added files finish processing in Live Monitor mode, the engine uses a 10-second idle debounce delay. Once the folder stabilizes, it performs a single, clean rewrite of the report.txt file—complete with updated directory scan statistics, total saved space, and current destination folder size—followed by a success log in the console.
5. Advanced Color & Metadata Optimization
Photos captured with phones and digital cameras contain hidden EXIF data, such as camera model, exposure settings, timestamps, and sensitive GPS geolocation. The "Strip EXIF" feature scrubs this non-image metadata without modifying image pixels, protecting personal privacy and trimming unnecessary file weight.
Images prepared for print commonly use the CMYK color space, which displays incorrectly in modern web browsers and bloats file sizes. Enabling "CMYK to RGB" automatically converts print profiles to web-standard sRGB for reliable color accuracy across all displays.
6. Process Controls & Audit Reports
Yes, you have complete control over the workflow:
  • Pause & Resume: Click Pause at any time to temporarily suspend optimization, and click Resume to seamlessly continue.
  • Cancel & System Tray: You can safely abort the process using Cancel, or minimize the application to the System Tray for quiet background execution.
  • Close & Resume Later: You can close the app at any point. When you reopen it and reload your saved preset, the Smart File Existence Check automatically detects previously optimized files in the destination folder and Skips them—effortlessly resuming right where you left off without redundant re-processing.

৪. স্মার্ট ব্যাচিং ও লাইভ মনিটর
এই ফিচারের মাধ্যমে অ্যাপটি ব্যাচ প্রসেসিংয়ের সময় অত্যন্ত বুদ্ধিমত্তার সাথে যাচাই করে যে, কোনো ছবি ডেস্টিনেশন ফোল্ডারে ইতিমধ্যে অপ্টিমাইজড অবস্থায় আছে কি না। ফাইলটি আগে থেকেই তৈরি থাকলে অ্যাপটি অপ্রয়োজনীয় ডুপ্লিকেট প্রসেসিং এড়িয়ে সেটিকে স্বয়ংক্রিয়ভাবে Skip করে দেয়। এটি সিস্টেম রিসোর্স বাঁচায় এবং বড় ব্যাচের ক্ষেত্রে নাটকীয়ভাবে সময় সাশ্রয় করে।
"Live Monitor" অপশনে টিক দিয়ে অপ্টিমাইজেশন চালু করলে প্রাথমিক ব্যাচ শেষ হওয়ার পর অ্যাপটি ব্যাকগ্রাউন্ডে সোর্স ফোল্ডারটি রিয়েল-টাইমে নজরদারিতে রাখে। ফোল্ডারে নতুন কোনো ছবি ড্রপ বা পেস্ট করামাত্রই অ্যাপটি তা শনাক্ত করে এবং স্বয়ংক্রিয়ভাবে অপ্টিমাইজ করে নেয়। স্ট্যাটাস বারে একটি লাইভ স্টপওয়াচের মাধ্যমে এর মোট অ্যাক্টিভ সময় (Active Time) প্রদর্শিত হয়।
লাইভ মনিটর চলাকালে ফোল্ডারে নতুন ফাইল আসা থামার পর সিস্টেম মাত্র ১০ সেকেন্ডের একটি স্মার্ট ডেবাউন্স ডিলে (Idle Delay) নিয়ে সম্পূর্ণ টপ সামারি (মোট ফাইল সংখ্যা, সাশ্রয়কৃত সাইজ এবং বর্তমান ডেস্টিনেশন ফোল্ডারের সাইজসহ) সহ report.txt ফাইলটি নিখুঁতভাবে রি-রাইট বা আপডেট করে নেয় এবং কনসোলে সাকসেস লগ দেখায়।

স্মার্টফোন বা ডিএসএলআর ক্যামেরায় তোলা ছবিতে ক্যামেরা মডেল, শাটার স্পিড এবং সংবেদনশীল GPS লোকেশন ডেটা লুকানো থাকে। "Strip EXIF" ফিচারটি ছবির মূল পিক্সেল কোয়ালিটি নষ্ট না করেই অপ্রয়োজনীয় মেটাডাটা মুছে ফেলে, যা ব্যবহারকারীর ব্যক্তিগত গোপনীয়তা রক্ষা করে এবং ছবির ওজন আরও হালকা করে।
প্রেস বা প্রিন্টিংয়ের জন্য তৈরি ছবিগুলো সাধারণত CMYK মোডে থাকে, যা সাধারণ ওয়েব ব্রাউজারে বিকৃত দেখায় বা অতিরিক্ত ফাইল সাইজ তৈরি করে। "CMYK to RGB" ফিচারটি এ ধরনের ছবিকে স্বয়ংক্রিয়ভাবে ওয়েব-স্ট্যান্ডার্ড sRGB মোডে রূপান্তর করে নির্ভুল ডিসপ্লে নিশ্চিত করে।
